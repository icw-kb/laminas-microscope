### Added
- Initial release of Laminas Microscope
- Comprehensive debugging and profiling suite for Laminas MVC
- Integration of Whoops error handler with beautiful error pages
- Debug Bar with request profiling and query logging
- Microscope code analysis with N+1 query detection
- Pure YAML-based configuration system
- Environment-specific configuration profiles
- Web interface for configuration management
- Programmatic component control
- Zero overhead for disabled components
- Automatic report storage and cleanup
- Export functionality for analysis reports

### Features
- **Whoops Integration**: Beautiful error pages with stack traces
- **Debug Bar**: Performance profiling toolbar
- **Microscope Analysis**: Code analysis and optimization insights
- **Configuration Profiles**: Predefined setups for different scenarios
- **Environment Support**: Development, staging, and production configs
- **Web Dashboard**: Browser-based configuration and analysis interface
- **API Endpoints**: Programmatic control via REST API
- **Security Features**: IP whitelisting and environment restrictions
